# Testing strategy

Test-driven development (TDD).

| Level | Scope |
|---|---|
| Domain and journal | Pure tests, no filesystem and no UI |
| `core/fs` | Against temporary directories, with images **generated by the test itself** |
| Integrity test | *Reverting a session leaves the file tree exactly as it was* |
| Performance | Sustained 16 ms frame budget; the next image already decoded before the keystroke |

No test uses real photographs or paths from the development machine.

## Running the suite

```bash
flutter test
dart analyze --fatal-infos
```

The core (`domain/`, `core/journal/`, `core/fs/`, `core/scanner/`, `core/preview/`) is pure
Dart with no dependency on Flutter, so its tests run without Xcode or Visual Studio
installed — only the Dart SDK is required. Widget and integration tests under `test/`
that touch `ui/` or `state/` do need the full Flutter toolchain.
