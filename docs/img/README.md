# Capturas del README

Los README enlazan estas capturas. Hechas el 20/09/2026 con el escenario de ejemplo de
`/Users/Shared/tria-demo` (imágenes generadas, nunca fotos reales). Nombres exactos:

| Archivo | Qué capturar |
|---|---|
| `setup.png` | Pantalla de configuración, con la carpeta de origen elegida y varios destinos asignados a las teclas |
| `triage.png` | Pantalla de triaje en marcha: vista previa de una imagen, panel de destinos y barra de progreso |
| `summary.png` | Pantalla de resumen al terminar una sesión, con los recuentos por destino |
| `trash.png` | Diálogo de confirmación antes de vaciar la papelera |

Usa datos de ejemplo, no carpetas reales: los nombres de archivo **y las rutas** salen en
la captura y el repositorio es público. Monta el escenario bajo `/Users/Shared/`, no bajo
tu carpeta personal: la ruta se ve entera en la pantalla de configuración.

Ancho recomendado: 1600 px (pantalla Retina a 2x escalada a la mitad). Guarda el PNG con
paleta de 256 colores: la interfaz es oscura y plana, se ve igual y ocupa una cuarta parte.
